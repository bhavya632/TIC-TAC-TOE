# TIC-TAC-TOE

A simple static Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Project structure

- `index.html` - game page
- `css/style.css` - styles
- `js/script.js` - game logic
- `fonts/` - custom font files
- `img/` - image assets

## How to run locally

1. Open `index.html` in your browser.

Or run a local server from the project folder:

```bash
python3 -m http.server 8000
```

Then open:

```
http://localhost:8000
```

## GitHub Pages

This project can be hosted directly on GitHub Pages.

1. Push the repository to GitHub.
2. Go to `Settings` → `Pages`.
3. Set source to `main` branch and folder `/ (root)`.
4. Save.

The public site should be available at:

```
https://bhavya632.github.io/TIC-TAC-TOE/
```
